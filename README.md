### Project Description
LOOPLEARN is a dynamic platform that empowers individuals to share their skills,connect with them and grow their expertise by trading knowledge.

### The Problem statement
Many individuals face barriers such as high cost of professional courses,lack of access to quality learning resources and the inability to connect with the right mentors or peers.

### The Solution
A skill swap app that serves as a peer-to-peer platform where users can exchange skills and knowledge seamlessly.

### Project Documentation
For Software:The SkillSwap website is a platform for users to connect and exchange skills such as music, dance, art, coding, and more. Built with HTML, CSS, JavaScript, and Firestore, it allows users to create profiles, specify skills they have and want to learn, and search for skills. Firestore securely stores user data, while the responsive design ensures usability across devices. Key features include a skill search bar, user profiles with detailed skill information, and easy navigation through tabs like About, FAQ, and Contact. Future enhancements include chat functionality and scheduling features.
